自由账本 V2 · 安卓安装说明

一、仅体验：将“自由账本_V2_单文件版.html”保存到安卓手机，在 Chrome 或文件管理器中打开。可以记账，但本地 file:// 页面的数据存储因浏览器而异，且不保证能安装为真正的桌面应用。

二、推荐作为安卓桌面 APP 使用（GitHub 并非唯一途径）：
1. 解压本 ZIP，上传其中 index.html、manifest.webmanifest、sw.js、icon.svg 四个文件到同一个 HTTPS 网站的目录，保持文件名不变。例如 GitHub Pages。
2. 使用安卓 Chrome 打开发布的 HTTPS 网页。
3. Chrome 菜单 → 安装应用 或 添加到主屏幕（名称随 Chrome 版本有所不同）。
4. 首次联网打开应用，稍后即可离线打开；请先断网测试能否进入应用，再正式开始长期记账。

三、重要数据说明：
- 账本数据保存在当前手机浏览器/已安装网页应用的本地存储，不会上载到 GitHub。不要向公共仓库上传任何 JSON 数据备份。
- 同一应用网址更新部署有机会继承原本的本地数据；更换网址、浏览器或安装方式可能无法共享旧账本记录。
- 清理站点数据、卸载、换机可能导致数据丢失。至少每周到「设置」导出完整 JSON 备份，另存到可靠位置。
- 从 V1 升到 V2，如仍使用同一个 HTTPS 地址及相同浏览器存储环境，旧流水可继续使用。仍建议升级前先导出 V1 备份。
- 债务余额功能只按登记后关联的“归还本金”扣减本金。利息不应计入归还本金。
- 预测仅为情景测算，不代表到期一定有足够现金。
